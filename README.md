# Food Store - Programacion II
- integrantes: Estrella Agustin, Valentino Nazar
## Requisitos
- Python 3.12 o superior.

## Ejecucion
Desde la carpeta principal del proyecto, ejecutar:

```bash
python main.py
```

Para ejecutar las pruebas del modelo y los servicios:

```bash
python pruebas.py
```

## Organizacion
- `entidades/`: clases del modelo y la interfaz Calculable.
- `enums/`: enumerados Rol, Estado y FormaPago.
- `excepciones/`: excepciones propias.
- `servicios/`: reglas de negocio y colecciones en memoria.
- `consola/`: menus, lectura y validacion de entradas.
- `main.py`: inicializacion y control del inicio de sesion.
- `pruebas.py`: pruebas del modelo y los servicios.
- `Informe_Food_Store.pdf`: informe del proyecto.
